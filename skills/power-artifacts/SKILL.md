If `POWER_BIN` is unset, you are not inside Power. Say so and stop, unless the user
gave you a `--box` selector for an external Power box. In that case, use `power`
on PATH in place of `"$POWER_BIN"`.

Load the release-matched guide with `"$POWER_BIN" skills get power-artifacts`
and follow it. Never guess flags from memory.
