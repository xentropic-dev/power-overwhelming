# Built-in color schemes

`wezterm.json` is the full WezTerm color catalog from [revision 7d0eb96](https://github.com/wezterm/wezterm/blob/7d0eb9685cbee56340ccd17926abdaf286a2f977/docs/colorschemes/data.json). The catalog carries scheme names, aliases, source URLs, and authors where supplied. [WezTerm license](wezterm.LICENSE.md)

`vscode.json` contains the native terminal colors for [Dark 2026](https://github.com/microsoft/vscode/blob/0089444c17dd066ec8a78e3a941e9f39bb93ec83/extensions/theme-defaults/themes/2026-dark.json) and [Light 2026](https://github.com/microsoft/vscode/blob/0089444c17dd066ec8a78e3a941e9f39bb93ec83/extensions/theme-defaults/themes/2026-light.json), with their indexed ANSI colors from the [terminal color registry](https://github.com/microsoft/vscode/blob/0089444c17dd066ec8a78e3a941e9f39bb93ec83/src/vs/workbench/contrib/terminal/common/terminalColorRegistry.ts). [VS Code license](vscode.LICENSE.txt)
